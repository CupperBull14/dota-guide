# Dota Guide

Справочник по Dota 2 на русском: гайды по 15 героям (способности, прокачка, таланты, предметы,
тактика, контрпики), справочник всех 127 героев игры, интерактивная карта, раздел для новичков, избранное
и инструменты: подбор героя, помощник «Против кого», сравнение героев, изменения патча и разбор
своих матчей по данным OpenDota. Тёмный дизайн в стиле Dota 2 с анимациями.

**Стек:** React 18 · TypeScript · Vite 5 · Tailwind CSS 3 · Framer Motion 11 · React Router 6 · lucide-react · Vitest.
**Патч данных:** 7.41 (значение `PATCH` в `src/data/constants.ts`).

## Быстрый старт

Нужен **Node.js 18 или новее** — проверить: `node -v`. Скачать: <https://nodejs.org> (версия LTS).

```bash
cd dota-guide
npm install       # один раз, и после каждого обновления package.json
npm run dev       # режим разработки → http://localhost:5173
```

На Windows команды вводятся в **cmd**: открой папку `dota-guide` в Проводнике, впиши `cmd` в адресную строку и нажми Enter.
Остановить сервер разработки — `Ctrl + C`.

### Все команды

| Команда | Что делает |
|---|---|
| `npm run dev` | Сервер разработки с горячей перезагрузкой |
| `npm test` | Все тесты (195): данные, фильтры, поиск, карта, подбор, помощник, сравнение, разбор матчей, смоук-тесты всех страниц |
| `npm run update:data` | Скачивает официальные данные героев с dota2.com (см. раздел «Обновление данных») |
| `npm run typecheck` | Только проверка типов TypeScript |
| `npm run build` | Проверка типов + production-сборка в папку `dist/` |
| `npm run preview` | Локальный просмотр собранной версии из `dist/` → http://localhost:4173 |

## Страницы

| Адрес | Что там |
|---|---|
| `/` | Баннер, поиск героя (↑ ↓ Enter Esc), «Случайный герой», категории, счётчики, блок для новичков |
| `/heroes` | Каталог: фильтры (атрибут, роль, сложность, линия, «новичку»), поиск, сортировка. Состояние в URL: `/heroes?attr=str&role=carry` |
| `/heroes/:slug` | Гайд по герою, например `/heroes/sven` |
| `/map` | Интерактивная карта: зоны, вкладки «Руны / Варды / Ротации», легенда |
| `/beginners` | Основы, роадмап «Первые 10 матчей» (с прогрессом), глоссарий, герои для новичков |
| `/favorites` | Избранные герои (хранятся в `localStorage` браузера) |
| `/pick` | Подбор героя: 7 вопросов → три героя под твой стиль. Ответы кодируются в ссылке `?r=…` |
| `/counter` | «Против кого я играю»: выбери героев врага (и своего) — опасности, что купить, на что смотреть. `?me=sniper&vs=riki,axe` |
| `/compare` | Сравнение двух героев: характеристики, способности, матчап. `?a=sven&b=zeus` |
| `/patch` | Что изменилось у героев в последнем патче (из `changelog.json`) |
| `/me` | Разбор последних матчей игрока по открытым данным OpenDota: сводка, сравнение с другими игроками на тех же героях, советы, связь с роадмапом. `?id=<Friend ID>` |
| всё остальное | Страница 404 |

## Обновление данных

Способности (перезарядка, мана), таланты, роли и список всех героев берутся из официального фида dota2.com.

```bash
npm run update:data                        # скачать всё и обновить src/data/generated/
npm run update:data -- --patch 7.42        # явно указать номер патча
npm run update:data -- --offline <папка>   # взять файлы из папки (herolist.json, herodata-<id>.json)
```

Команда:
1. пересобирает `heroes-index.json` (127 героев: имя, атрибут, роли, тип атаки);
2. обновляет `hero-details.json` для героев с гайдом;
3. сравнивает с прошлым снимком и дописывает изменения в `changelog.json` (страница `/patch`);
4. пишет `meta.json` — номер патча и дату (его показывает футер и `PATCH` в `constants.ts`).

После обновления запусти `npm test`: если Valve изменила структуру данных, тесты это покажут.
Тексты гайдов, билды предметов, тайминги карты и описания предметов обновляются **вручную** —
по официальным заметкам патча (`https://www.dota2.com/patches/<версия>`) и статистике.

## Разбор матчей (`/me`)

Страница обращается из браузера к открытому API OpenDota (`api.opendota.com`) — ключ не нужен,
лимит около 60 запросов в минуту. Никакие данные игрока не сохраняются на сервере: в `localStorage`
лежит только последний введённый ID.

- Принимает Friend ID, SteamID64 и ссылки Steam (`/profiles/…`), Dotabuff, OpenDota, STRATZ.
  Ссылки вида `steamcommunity.com/id/имя` не поддерживаются — без ключа Steam их нельзя превратить в ID.
- Анализируются последние ~20 матчей. Турбо (режим 23) показывается, но в средние не входит.
- Перцентили — по `/benchmarks?hero_id=…` для трёх самых частых героев игрока.
- Если профиль закрыт, страница объясняет, как включить «Expose Public Match Data» в настройках Dota 2.
- Данных о вардах в ответе OpenDota нет, поэтому советов по вардам страница не даёт.
- Шаги роадмапа отмечаются пройденными только по нажатию кнопки.

## Как добавить героя

1. Скопируй любой файл из `src/data/hero-list/`, например `axe.ts`, и заполни поля.
   `id` — латиница в нижнем регистре через дефис: он станет адресом `/heroes/<id>`.
2. Добавь импорт и героя в массив `RAW` в `src/data/heroes.ts`.
3. Для портрета добавь внутреннее имя героя в `VALVE_KEYS` (там же), для иконок способностей —
   запись в `ABILITY_ICONS` в `src/data/icons.ts`. Без них сайт покажет стилизованные заглушки.
4. Если нужны новые предметы — добавь их в `src/data/items.ts` и иконку в `ITEM_ICONS`.
5. Запусти `npm test`: тесты проверят прокачку, таланты, предметы, иконки и ссылки.

Контрпики и синергии автоматически становятся ссылками, если имя совпадает с героем из базы.

## Публикация (хостинг)

Сайт — статический: после `npm run build` достаточно выложить папку `dist/`.
Это SPA, поэтому хостинг должен отдавать `index.html` на любой адрес — для популярных площадок это уже настроено:

- **Netlify** — перетащи папку `dist` на <https://app.netlify.com/drop>. Файл `public/_redirects` уже в проекте.
- **Vercel** — импортируй репозиторий, Framework: Vite. Файл `vercel.json` уже в проекте.
- **Cloudflare Pages** — Build command `npm run build`, Output `dist`. Правило из `_redirects` подхватится само.
- **GitHub Pages** — уже настроено: workflow `.github/workflows/deploy.yml` сам собирает сайт при каждом пуше в `main`.
  В репозитории открой Settings → Pages → Source: **GitHub Actions**. Адрес: `https://<логин>.github.io/<имя-репозитория>/`.
  Базовый путь берётся из переменной `VITE_BASE` (локально не нужна), `404.html` создаётся автоматически.

Портреты, рендеры и иконки грузятся с официального CDN Valve, данные матчей — с OpenDota. Перед публичным запуском
ознакомься с правилами Valve для фанатских сайтов.
